# 王麒昀 - 首席大提琴家 & 教育家

> "于弦音之间，寻觅古典与现代的学术交响。"

王麒昀个人主页，展示艺术成就、教学理念与专业背景。

## 技术栈

- **React 19** + **TypeScript**
- **Vite** 构建工具
- **Tailwind CSS 4** 样式框架
- **Framer Motion** 动效库
- **Lucide React** 图标库

## 页面结构

| 模块 | 内容 |
|------|------|
| Hero | 全屏展示区，中英文名 + 肖像照 |
| 艺术传记 | 个人背景与演奏风格介绍 |
| 学术档案 | 利兹大学 / 伯克利 / 耶鲁进修经历 |
| 艺术荣誉 | 比赛金奖、协会会员资质 |
| 艺术垂询 | 联系电话与邮箱 |

## 本地运行

**前置条件:** Node.js

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:3000 查看页面。

## 构建部署

```bash
npm run build
```

构建产物输出至 `dist/` 目录，可部署至任意静态托管服务。
