## 一、本地已有资产

> **统一入口已合并**：VISTA 组件库与帆软组件库融合为一个演示中心（9999 端口），
> 帆软素材以「帆软·」前缀分类显示，两张演示大屏挂在顶栏按钮上。

### 1. 统一组件演示中心（9999）⭐

- **位置**：`vista-dashboard-components/`（`python server.py` → http://127.0.0.1:9999）
- **VISTA 自有组件**：大标题（1.0/3.0）、小标题 2.0、标题框、数据底板、指标按钮、通用面板
- **帆软· 8 个分类（456 项）**：大屏背景 / 长屏背景 / 大标题 / 组件标题 / 组件面板 / 分割线 /
  图标 / 市场参考 —— 提取自帆软官方《数据可视化指南》素材包 + 市场热度预览图，全部透明切片，
  已脱离设计器可自由拼接
- **顶栏演示页**：
  - 销售驾驶舱复刻 http://127.0.0.1:9999/demo-report.html （官方 .frm 模板复刻）
  - 医疗监测大屏 http://127.0.0.1:9999/demo-dashboard.html （素材拼装示例）
- **FineReport 模板文件**：`fanruan-components/templates/`（官方 .frm 驾驶舱 + 9 张 .cpt 费用预算报表 + SQL），
  可直接用本机 FineReport 打开

- FineReport 模板与原始素材包：`fanruan-components/templates/`（.frm/.cpt）、`fanruan-extract/downloads/`（9 个官方 zip + rar）

### 1. VISTA 大屏组件切片库（已并入 9999 统一中心）

- **位置**：`vista-dashboard-components/`
- **来源**：https://github.com/det5chen/vista-dashboard-components.git（已克隆到本地）
- **内容**：大屏可视化看板组件切片，含 PNG / SVG / **PSD 源文件**，可直接改色改形状

| 分类 | 说明 |
| ---- | ---- |
| 大标题 | 看板主标题样式，1.0 / 3.0 两代 |
| 小标题 | 模块小标题样式 2.0 |
| 标题框 | 标题框组件切片（面板1.0） |
| 数据底板 | 数据引擎 / 状态底板系列 |
| 指标按钮 | 大屏指标按钮，30+ 种样式 |
| 通用面板 | 通用容器面板 |

- **打开方式**：`cd vista-dashboard-components && python server.py` → http://127.0.0.1:9999
  自带分类导航、搜索、单击放大预览、复制资源路径、明暗主题切换

### 2. 深色看板画廊 Dark Dashboard Gallery

- **位置**：`dark-dashboard-gallery/`（根目录的 `dashboard-*.html` 是其中各主题的单页副本）
- **内容**：一份数据、九种表达，全部**单文件、零构建**，ECharts 渲染，3 秒模拟刷新
  - **4 个行业主题大屏**（`themes/`）：工业智造、全域营销销售、智慧医疗、星际算力监控
    - 签名组件：OEE 辉光仪表盘、水位图、五级转化漏斗、实时心电波形、粒子星空
  - **5 种设计语言对照**（`styles/`）：Terminal 终端风 / Linear 工具风 / Tufte 数据墨水风 / Vercel 风格 / Y2K 风格
    - 同一份数据的五种排版解法，适合做"同一需求不同气质"的对照参考
  - **1 套组件库**：`components.html`（Aurora UI）
- **打开方式**：双击 `index.html` 从总览页开始浏览

### 3. amis 低代码预览项目

- **位置**：`amis-demo/`
- **内容**：基于百度 [amis](https://aisuda.bce.baidu.com/amis/zh-CN/docs/index) SDK（CDN 引入、无需构建）的仪表盘项目
  - `viewer.html` 读 `page.json` 渲染，改 JSON 刷新即生效，`mock.json` 提供 CRUD 卡片 mock 数据
- **打开方式**：`python -m http.server 8090` → http://127.0.0.1:8090/viewer.html

### 4. 数字人助手（非看板组件，顺带收录）

- **位置**：`digital-human/`
- **内容**：开源实时数字人，一张照片 + 一块显卡，可语音对话、带 AI 口型；适合做大屏的"虚拟讲解员"补充

## 四、场景速查

| 我要做什么 | 用哪个 |
| ---- | ---- |
| 摆脱设计器、自己拼大屏（标题/面板/图标全透明切片） | **fanruan-components 本地库** |
| 给 FineReport/FineBI 大屏换标题、面板、按钮皮肤 | VISTA 切片库（PSD 可改）或帆软组件复用 |
| 找现成大屏模板直接套 | 帆软市场模板 / DataRoom / FlyFish |
| 写代码搭大屏，要边框装饰类代码组件 | DataV + ECharts |
| 参考不同设计语言的排版气质 | 深色看板画廊 5 风格对照 |
| 不写代码、拖拽出大屏 | GoView / FlyFish / 帆软大屏设计器 |
| 低代码 JSON 配置出管理仪表盘 | amis（见 amis-demo） |
