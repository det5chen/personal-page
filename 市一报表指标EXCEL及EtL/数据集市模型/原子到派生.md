# 市一医院 — 原子层 → 派生层 ETL 完整设计文档

> 14 张原子表 → 8 条 ETL 链路 → 8 张派生表

---

## 一、整体架构

```
原子层 (atomic) 14张表 ──8条ETL──→ 派生层 (derived) 8张表
```

| 序号 | 目标派生表 | 来源原子表 | 字段数 |
|:---:|---|---|:---:|
| 01 | ENC_DERIVED | ENC_EMER_OUTP_VISIT + ENC_INP_VISIT + ENC_BED_RECORD | 16 |
| 02 | REV_DERIVED_RX_ORD | ORD_RX_OUTP_PRESCRIPTION + ORD_INP_ORDER + ORD_MED_OUTP_USAGE + ORD_MED_INP_USAGE | 27 |
| 03 | FEE_DERIVED | FEE_OUTP_VISIT + FEE_INP_VISIT | 26 |
| 04 | REV_DERIVED_AUDIT | REV_RX_OUTP_AUDIT_REVIEW + REV_ORD_INP_AUDIT + REV_MR_DISCHARGE_REVIEW | 20 |
| 05 | MDM_DERIVED_STAFF | MDM_STAFF | 12 |
| 06 | SURG_DERIVED | SURG_RECORD + ORD_MED_INP_USAGE | 12 |
| 07 | NUR_DERIVED | NUR_INFUSION_INP_RECORD + NUR_INFUSION_OUTP_RECORD + NUR_IVADMIX_RECORD | 19 |
| 08 | ADR_DERIVED | ADR_RECORD | 10 |

> 8 条 ETL 均为域内聚合，无跨链路依赖，可全部并行执行。

## 三、派生层 8 张表字段映射

### 3.1 ENC_DERIVED（就诊派生表）

| 字段名 | 含义 | 来源 & 加工逻辑 |
|---|---|---|
| outpatient_visits | 门诊人次 | ENC_EMER_OUTP_VISIT: `COUNT(DISTINCT CASE WHEN visit_type_name LIKE '%门诊%' OR visit_type_code IN('1','01') THEN register_id END)` |
| emergency_visits | 急诊人次 | ENC_EMER_OUTP_VISIT: `COUNT(DISTINCT CASE WHEN visit_type_name LIKE '%急诊%' OR visit_type_code IN('2','02') THEN register_id END)` |
| outpatient_emergency_visits | 门急诊总人次 | P01+P02 |
| discharges | 出院人数 | ENC_INP_VISIT: `COUNT(DISTINCT CASE WHEN discharge_way_code IS NOT NULL AND <>'' THEN admission_id END)` |
| admissions | 入院人数 | ENC_INP_VISIT: `COUNT(DISTINCT admission_id)` |
| actual_open_beds | 实际开放床位数 | ENC_BED_RECORD: `COUNT(DISTINCT CASE WHEN open_flag='1' THEN bed_id END)` |
| discharge_count | 出院人次(副本) | 同 discharges |
| non_surgical_inpatients | 非手术住院人数 | ENC_INP_VISIT: `COUNT(DISTINCT CASE WHEN NVL(surgery_flag,'0')='0' THEN admission_id END)` |
| total_inpatient_occupied_bed_days | 占用总床日 | ENC_BED_RECORD: `SUM(CASE WHEN NVL(occupy_flag,'0')='1' THEN TO_NUMBER(NVL(bed_day,'0')) ELSE 0 END)` |

JOIN方式: `FULL JOIN` 三路，`ward_code` 用 `NVL(…,'-')` 处理NULL

### 3.5 MDM_DERIVED_STAFF（人员派生表）

单表聚合 `MDM_STAFF`，全部为 `COUNT(DISTINCT staff_id)` + 不同条件:

| 字段名 | 含义 | 筛选条件 |
|---|---|---|
| pharmacist_count | 药师人数 | staff_type 含"药师" 或 code IN('药师','03') |
| clinical_pharmacist_count | 临床药师人数 | qualification 含"临床药师" 或 code='临床药师'/'01' |
| physician_count | 医师人数 | staff_type 含"医师" 或 code='医师'/'01' |
| pharmacy_technicians_count | 药学专业技术人员数 | staff_type 含"药学" 或 code='药学'/'03' |
| health_professionals_count | 卫生专业技术人员数 | staff_type 含"卫生" 或 code='卫生'/'04' |

⚠ pharmacist_count 和 pharmacy_technicians_count 使用相同 code 条件，需核实区分。

## 五、已知问题汇总

| 编号 | 位置 | 严重程度 | 问题描述 |
|:---:|---|---|---|
| BUG-1 | SURG_DERIVED S03 | 🔴 高 | Ⅰ类切口静脉预防抗菌≤24h 与 S02 逻辑完全相同，缺 ≤24h 过滤，分子=分母 |
| BUG-2 | SURG_DERIVED S05 | 🔴 高 | Ⅱ类切口静脉预防抗菌≤24h 与 S04 逻辑完全相同，缺 ≤24h 过滤 |
| BUG-3 | NUR_DERIVED N12 | 🔴 高 | 急诊糖皮质激素输液人数 与 N01(急诊输液人数) 完全相同，缺糖皮质激素过滤 |
| MIS-1 | FEE_DERIVED 多处 | 🟡 中 | drug_rev/medical_rev/supplies_rev 等金额指标使用 `COUNT(*)` 占位，应替换为 `SUM(amount)` |
| MIS-2 | FEE_DERIVED F19/F20 | 🟡 中 | DDL定义了基本药物费用字段，INSERT 未实现 |
| MIS-3 | NUR_DERIVED N05/N06 | 🟡 中 | 输液体积/数量使用 `COUNT(*)` 占位，应为 `SUM(volume)/SUM(quantity)` |
| MIS-4 | REV_DERIVED_RX_ORD | 🟢 低 | DDD 用 `SUM(1)` 近似，实际应使用 ddd_value 字段求和 |
| MIS-5 | MDM_DERIVED_STAFF | 🟢 低 | pharmacist_count 与 pharmacy_technicians_count 使用相同 code 条件 |
