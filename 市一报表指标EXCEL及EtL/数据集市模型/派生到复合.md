# 市一医院 — 派生层 → 复合层 ETL 完整设计文档

> 8 张派生表 → 9 条 ETL 链路 → 9 张复合(指标)表

---

## 一、整体架构

```
派生层 (derived) 8张表 ──9条ETL──→ 复合层 (composite) 9张指标表
```

| 序号 | 目标复合表 | 来源派生表 | 指标字段数 |
|:---:|---|---|:---:|
| 01 | ENC_DERIVED_IDX | ENC_DERIVED + REV_DERIVED_RX_ORD | 12 |
| 02 | REV_DERIVED_IDX | REV_DERIVED_AUDIT + REV_DERIVED_RX_ORD | 12 |
| 03 | RX_ORD_DERIVED_IDX | REV_DERIVED_RX_ORD + FEE_DERIVED + ENC_DERIVED + NUR_DERIVED | 18 |
| 04 | FEE_DERIVED_IDX | FEE_DERIVED + ENC_DERIVED + REV_DERIVED_RX_ORD | 12 |
| 05 | SUP_DERIVED_IDX | 外部供应链系统(占位) | 9 |
| 06 | NUR_DERIVED_IDX | NUR_DERIVED + ENC_DERIVED | 11 |
| 07 | SURG_DERIVED_IDX | SURG_DERIVED | 3 |
| 08 | MDM_DERIVED_IDX | MDM_DERIVED_STAFF + ENC_DERIVED | 5 |
| 09 | ADR_DERIVED_IDX | ADR_DERIVED + ENC_DERIVED | 3 |

> 需先执行全部 原子→派生 ETL（8条链路），再按序执行本目录脚本。

---

## 二、派生层 8 张表按域分类（数据来源）

| 域 | 派生表 | 主要内容 |
|---|---|---|
| 就诊域 | ENC_DERIVED | 门诊/急诊人次、出入院人数、床位、床日 |
| 处方医嘱域 | REV_DERIVED_RX_ORD | 处方总数、用药人数、DDD、基本药物 |
| 费用域 | FEE_DERIVED | 药品/医疗/材料收入、抗菌费用 |
| 处方点评域 | REV_DERIVED_AUDIT | 审核/点评/合理率分子 |
| 人员域 | MDM_DERIVED_STAFF | 药师/医师/技术人员人数 |
| 手术域 | SURG_DERIVED | 切口手术台数、预防抗菌台数 |
| 护理域 | NUR_DERIVED | 输液人数/床日/体积、静配统计 |
| 不良反应域 | ADR_DERIVED | ADR上报数、用药错误 |

## 三、复合层 9 张指标表字段映射

### 3.1 ENC_DERIVED_IDX（就诊域指标表）

来源: `derived.ENC_DERIVED e LEFT JOIN derived.REV_DERIVED_RX_ORD rx`

| 字段名 | 含义 | 计算公式 |
|---|---|---|
| outpatient_visits | 门诊就诊人次数 | 直传 e.outpatient_visits |
| emergency_visits | 急诊就诊人次数 | 直传 e.emergency_visits |
| outpatient_emergency_visits | 门急诊人次数 | 直传 e.outpatient_emergency_visits |
| discharges | 出院人数 | 直传 e.discharges |
| admissions | 入院人数 | 直传 e.admissions |
| total_visits | 总诊疗人次数 | 门诊 + 急诊 + 入院 ⚠缺出诊/健康检查/健康咨询 |
| actual_open_beds | 实际开放床位数 | 直传 e.actual_open_beds |
| outpatient_essential_drug_visits_ratio | 门诊使用基本药物人次比 | rx.outpatient_essential_drug_visits / e.outpatient_visits × 100% |
| outpatient_essential_drug_prescription_ratio | 门诊患者基本药物处方占比 | rx.outpatient_essential_drug_prescriptions / rx.total_outpatient_prescriptions × 100% |
| outpatient_essential_drug_usage_ratio | 门诊患者基本药物处方使用占比 | rx.outpatient_essential_drug_visits / e.outpatient_visits × 100% ⚠与人次比相同 |
| inpatient_essential_drug_usage_rate | 住院患者基本药物使用率 | rx.inpatients_using_essential_drugs / e.discharges × 100% |
| inpatient_essential_drug_usage_ratio | 住院患者基本药物使用占比 | rx.inpatients_using_essential_drugs / e.discharges × 100% ⚠与使用率相同 |

### 3.3 RX_ORD_DERIVED_IDX（处方医嘱域指标表）

| inpatient_tcm_injection_usage_rate | 住院患者中药注射剂使用率 | rx.inpatients_using_tcm_injection / e.discharges × 100% |
| inpatient_ppi_injection_usage_rate | 住院患者PPI注射剂使用率 | rx.inpatients_using_ppi_injection / e.discharges × 100% |
| inpatient_acid_suppressant_injection_usage_rate | 住院患者抑酸注射剂使用率 | rx.inpatients_using_acid_suppressant_injection / e.discharges × 100% |
| inpatient_antibiotic_injection_usage_rate | 住院患者抗菌药物注射剂使用率 | rx.inpatients_using_antibiotic_injection / e.discharges × 100% |
| inpatient_antiemetic_injection_usage_rate | 住院患者止吐药注射剂使用率 | rx.inpatients_using_antiemetic_injection / e.discharges × 100% |
| inpatient_parenteral_nutrition_usage_rate | 住院患者肠外营养使用率 | rx.inpatients_using_parenteral_nutrition / e.discharges × 100% |
| inpatient_single_bottle_pn_usage_ratio | 住院患者单瓶输注肠外营养使用占比 | rx.inpatients_using_single_bottle_pn / rx.inpatients_using_parenteral_nutrition × 100% |
| inpatient_multi_chamber_bag_pn_usage_rate | 住院患者工业化多腔袋肠外营养使用率 | rx.inpatients_using_multi_chamber_bag_pn / rx.inpatients_using_parenteral_nutrition × 100% |
| inpatient_all_in_one_pn_usage_rate | 住院患者全合一肠外营养使用率 | rx.inpatients_using_all_in_one_pn / rx.inpatients_using_parenteral_nutrition × 100% |
| emergency_glucocorticoid_iv_usage_rate | 急诊患者糖皮质激素静脉输液使用率 | n.emergency_patients_with_glucocorticoid_iv / e.emergency_visits × 100% |
| inpatient_antibiotic_usage_rate | 住院患者抗菌药物使用率 | rx.inpatients_using_antibiotics / e.discharges × 100% |
| inpatient_antibiotic_usage_intensity | 住院患者抗菌药物使用强度 | rx.total_inpatient_antibiotic_ddd / e.total_inpatient_occupied_bed_days × 100 |
| inpatient_special_grade_antibiotic_intensity | 住院患者特殊使用级抗菌药物使用强度 | rx.total_inpatient_special_grade_antibiotic_ddd / e.total_inpatient_occupied_bed_days × 100 |
| inpatient_special_grade_antibiotic_usage_ratio | 住院患者特殊使用级抗菌药物使用量占比 | f.inpatient_special_grade_antibiotic_cost / f.total_inpatient_antibiotic_cost × 100% |

### 3.4 FEE_DERIVED_IDX（费用域指标表）

来源: `derived.FEE_DERIVED f LEFT JOIN derived.ENC_DERIVED e LEFT JOIN derived.REV_DERIVED_RX_ORD rx`

| 字段名 | 含义 | 计算公式 |
|---|---|---|
| medical_service_revenue_ratio | 医疗服务收入占比 | (医疗总收入 - 药品收入 - 卫生材料收入) / 医疗总收入 × 100% ⚠缺检查/化验收入 |
| average_outpatient_drug_cost_per_visit | 门诊患者次均药费 | f.total_outpatient_drug_cost / e.outpatient_visits |
| average_drug_cost_per_capita | 人均药品费用(次) | (门急诊药品收入+住院药品收入) / (门诊+急诊+入院人数) |
| outpatient_average_drug_cost_growth_rate | 门诊次均药品费用增幅 | '0' 占位，需同比数据 |
| inpatient_average_drug_cost_growth_rate | 住院次均药品费用增幅 | '0' 占位，需同比数据 |
| adjuvant_drug_revenue_ratio | 辅助用药收入占比 | (门急诊辅助+住院辅助) / 医疗总收入 × 100% |
| key_monitored_drug_revenue_ratio | 重点监控药品占药品收入比例 | (门急诊+住院重点监控药品收入) / (门急诊+住院药品收入) × 100% |
| self_pay_drug_revenue_ratio | 自费药品占药品收入比例 | 自费药品收入 / (门急诊+住院药品收入) × 100% |
| discharges_with_tcm_decoction_ratio | 使用中药饮片的出院人数占比 | rx.discharges_with_tcm_decoction / e.discharges × 100% |
| total_outpatient_drug_cost | 门诊就诊患者药品总费用 | 直传 f.total_outpatient_drug_cost |
| total_emergency_drug_cost | 急诊就诊患者药品总费用 | 直传 f.total_emergency_drug_cost |
| outpatient_antibiotic_cost_ratio | 门诊抗菌药物费用占总药费比 | f.outpatient_antibiotic_cost / f.outpatient_drug_revenue × 100% |
| inpatient_antibiotic_cost_ratio | 住院抗菌药物费用占总药费比 | f.inpatient_antibiotic_cost / f.inpatient_drug_revenue × 100% |
